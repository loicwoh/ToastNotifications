# Toast Notifications for LabVIEW

[![Open documentation](https://img.shields.io/badge/Documentation-Open%20site-336699?style=for-the-badge)](https://loicwoh.github.io/ToastNotifications/)

Build interactive Windows notifications from LabVIEW, and receive activation
arguments and submitted text through a customizable handler.

- [Documentation and examples](https://loicwoh.github.io/ToastNotifications/)
- [Why this project](https://loicwoh.github.io/ToastNotifications/#/background)
- [Source project](Sources/Toast%20Notifications.lvproj)
- [Documentation maintenance](Sources/docs/README.md)
- [Current coverage and limitations](Sources/docs/site/coverage.md)

The development sources and examples are saved in **LabVIEW 2020** format.
Development continues in **LabVIEW 2026** on Windows with
Microsoft.Toolkit.Uwp.Notifications. The published `v1.0.0` VIPM package targets
LabVIEW 2026 64-bit.

`develop` is the integration branch and `main` is reserved for releases.
Documentation previews identify their branch and commit in the version selector.
