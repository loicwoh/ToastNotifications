# ToastAPI for LabVIEW

[![Open the ToastAPI documentation](https://img.shields.io/badge/Documentation-Open%20site-336699?style=for-the-badge)](https://loicwoh.github.io/ToastNotifications/)

Build interactive Windows notifications from LabVIEW and receive activation
arguments and submitted text through a customizable handler.

- [Getting started](https://loicwoh.github.io/ToastNotifications/#/getting-started)
- [Examples](https://loicwoh.github.io/ToastNotifications/#/examples)
- [LabVIEW source project](Sources/ToastAPI.lvproj)

Development takes place on [`develop`](https://github.com/loicwoh/ToastNotifications/tree/develop).
`main` is reserved for releases.
