# ToastAPI for LabVIEW

[![Open the ToastAPI documentation](https://img.shields.io/badge/Documentation-Open%20site-336699?style=for-the-badge)](https://loicwoh.github.io/ToastNotifications/)

ToastAPI is a LabVIEW toolkit for interactive notifications on Windows. Use it
to tell an operator that a long test has finished, ask them to make a choice,
or collect a short reply while they work in another window. Compose a toast
with LabVIEW VIs or start from an XML definition. An activation handler brings
button choices and submitted text into your application.

## Try it

- Follow [Getting started](https://loicwoh.github.io/ToastNotifications/#/getting-started) to open the toolkit in LabVIEW.
- Pick an [example](https://loicwoh.github.io/ToastNotifications/#/examples) to try a reply, a choice, a link, or a toast from XML.
- Browse the [API](https://loicwoh.github.io/ToastNotifications/#/api) and [known limits](https://loicwoh.github.io/ToastNotifications/#/coverage) to see what you can use in your application.
