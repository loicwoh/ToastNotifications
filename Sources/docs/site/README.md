# Interactive Windows notifications for LabVIEW

<p class="lead">Show a toast, offer an action or ask for a short reply, and handle the response in your LabVIEW application.</p>

<span class="pill">LabVIEW 2026</span><span class="pill">Windows desktop</span><span class="pill pending">In development</span>

When a long test finishes or needs a decision, a toast can reach the operator while they work in another window. ToastAPI lets you build the notification with LabVIEW VIs or supply an XML definition. A User Event handler can bring button choices and submitted text into your application's event loop. [Why this project exists](background.md)

## Contribute

Try an example, report something that did not work, or pick an open issue. A useful bug report includes your Windows and LabVIEW versions, the VI or example you used, and what you expected to happen.

For a code or documentation change, start from `develop` and open a pull request against it. Check the open issues for work already in progress and use the docs guide to build a local preview.
