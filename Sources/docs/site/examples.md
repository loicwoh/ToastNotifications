# Choose an example

Open **Toast Notification Examples.lvproj** in LabVIEW and pick an example.

| Where you are working | Project location |
|---|---|
| Source checkout | `Sources/Toast Notification Examples.lvproj` |
| VIPM installation | `<LabVIEW>/examples/Toast Notifications for LabVIEW/Toast Notification Examples.lvproj` |

After installation, find the toolkit VIs in **Functions → Addons → Toast Notifications**.

| If you want to… | Try |
|---|---|
| Collect a short reply from a notification | [Ask for a text reply](guides/reply.md) |
| Let someone accept or reject a request | [Offer a choice in a toast](guides/multiple-actions.md) |
| Take someone directly to a page or report | [Open a link from a toast](guides/protocol.md) |
| Reuse a notification design you already have as XML | [Reuse a toast definition from XML](guides/xml.md) |
| Show a result preview inside a toast | [Show a result preview](guides/images.md) |
